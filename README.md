# Alferova_Homework_Python

# Документация проекта

Автоматизированные UI-тесты для проверки веб-калькулятора с задержкой и оформления заказа в интернет-магазине Swag Labs. Проект реализован с применением паттерна **Page Object Model (POM)** и интегрирован с системой отчетности **Allure Report**.

---

## Описание базового синтаксиса записи и форматирования

### Стек технологий и правила оформления кода

* **Python**: Основной язык программирования для написания автотестов.
* **Selenium**: Библиотека для автоматизации взаимодействия с веб-браузером.
* **Pytest**: Фреймворк для написания и запуска тестов.
* **Allure**: Инструмент для генерации наглядных отчетов о выполнении тестов.
* **Стиль кода (PEP 8)**: Весь код отформатирован в соответствии со стандартом PEP 8.
* **Документирование (Docstrings и Type Hints)**: Все методы классов Page Object (`calculator_page_allure.py`, `shop_pages_allure.py`) содержат `docstrings`, а также аннотации типов входных параметров и возвращаемых значений.
* **Разметка Allure**: Действия и проверки в тестах (`test_calculator_allure.py`, `test_shop_allure.py`) оформлены через `@allure.step` и `with allure.step`, а сами тесты снабжены декораторами `@allure.title`, `@allure.description`, `@allure.feature` и `@allure.severity`.

### Базовый синтаксис разметки Markdown (для документации)

* **Заголовки** оформляются символом `#` (`#` — уровень 1, `##` — уровень 2, `###` — уровень 3).
* **Жирный текст** выделяется двойными звездочками: `**текст**`.
* *Курсив* выделяется одинарными звездочками: `*текст*`.
* `Встроенный код` или названия файлов заключаются в одинарные обратные кавычки: `` `test_shop_allure.py` ``.
* **Блоки кода** оборачиваются в тройные обратные кавычки с указанием языка (` ```bash `, ` ```python `).
* **Списки** создаются с помощью символов `*`, `-` или нумерации (`1.`, `2.`).

## Инструкция по запуску тестов для формирования отчета Allure

1. Установите необходимые зависимости из файла `requirements.txt`:

```bash
pip install -r requirements.txt
```

2. Запустите все тесты с сохранением результатов в директорию `./allure-results`:

```bash
pytest --alluredir=./allure-results
```

Для запуска конкретного тестового файла укажите его имя:

```bash
pytest test_calculator_allure.py --alluredir=./allure-results
pytest test_shop_allure.py --alluredir=./allure-results
```

*(Если команда `pytest` не распознается в терминале, используйте запуск через модуль Python: `python -m pytest --alluredir=./allure-results`).*

## Инструкция по просмотру сформированного отчета Allure

После завершения тестов, чтобы сгенерировать отчет и автоматически открыть его в браузере, выполните команду:

```bash
allure serve ./allure-results
```

Эта команда запустит локальный веб-сервер и откроет интерактивный отчет в браузере по умолчанию. Для остановки сервера после просмотра нажмите в терминале `Ctrl + C`.

### В отчете Allure отображаются:

* **Название тестов**: Например, *Тестирование медленного калькулятора: 7 + 8 = 15* и *Оформление заказа в интернет-магазине Swag Labs*.
* **Описание тестов**: Подробная информация о сценарии и целях проверки.
* **Функциональность и критичность**: Группировка по фичам (`Калькулятор`, `Интернет-магазин`) и уровни важности (`Critical`, `Blocker`).
* **Шаги и проверки**: Детальный пошаговый лог всех действий в браузере и проверок (`assert`).
* **Результат**: Статус прохождения тестов (`Passed` или `Failed`) с описанием ошибки при падении.
