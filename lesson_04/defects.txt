Дефект №1: Падение утилиты с ошибкой AttributeError при передаче значения None
- Шаги для воспроизведения: Вызвать метод utils.capitalize(None) или utils.trim(None)
- Ожидаемый результат: Программа обрабатывает исключение (например, возвращает пустую строку или вызывает TypeError с понятным описанием).
- Фактический результат: Критическое падение программы: "AttributeError: 'NoneType' object has no attribute 'capitalize'".
- Важность: High (Высокая, так как приводит к падению приложения).

Дефект №2: Метод trim() не удаляет спецсимволы табуляции (\t) и переноса строки (\n)
- Шаги для воспроизведения: Вызвать utils.trim("\t\nskypro")
- Ожидаемый результат: Строка "skypro".
- Фактический результат: Строка "\t\nskypro" (удаляются только пробелы " ").
- Важность: Low (Низкая).

Дефект №3: Метод delete_symbol() принимает списки вместо строк и возвращает их без изменений
- Шаги для воспроизведения: Вызвать utils.delete_symbol([], "a")
- Ожидаемый результат: Ошибка TypeError, так как класс предназначен исключительно для обработки строк (StringUtils).
- Фактический результат: Метод возвращает пустой список [], так как встроенный блок try-except внутри метода contains() непреднамеренно перехватывает ошибку поиска по списку (ValueError) и глушит её.
- Важность: Medium (Средняя, нарушение типизации данных).
